AXEL Architecture & Getting Started Guide

            
High-performance desktop intelligence, security boundaries, and Groq setup

          

        

        
      


      

        

          
          
          
          
        

      


      

        
        

          

            
Single-Binary Desktop Architecture

            
AXEL is engineered in pure Rust as a standalone native application to replace conventional operating system file managers with intelligent, zero-overhead document understanding. Unlike Electron or Python-based tools, AXEL runs within a lean memory budget (~10 MB RSS) with instantaneous sub-millisecond startup.

          

          

            
Zero Byte Duplication & Virtual Hierarchies

            
Conventional file systems force documents into rigid, single-path directory structures. AXEL computes dynamic Virtual Paths. A single file can belong to multiple logical constellations simultaneously (for example, a machine learning lecture note can be indexed under Academics/Data Science, Career/Coursework, and Research/AI) without duplicating physical bytes on your storage device.

          

          

            
Multi-Format Extraction & OCR

            
AXEL extracts clean semantic text across formats directly: pure-Rust PDF parsing via pdf-extract, zero-dependency DOCX XML document streaming, code symbol deconstruction, and automatic Tesseract OCR discovery for scanned PDFs and images.

          

          

            
Sub-Millisecond Hybrid Search & Galaxy Canvas

            
Search queries execute in sub-millisecond time across thousands of indexed files using hybrid score blending. The interactive Galaxy Canvas visualizes topic clusters, keyword constellations, and semantic links in real time with hardware-accelerated 60 FPS rendering.

          

        


        
        

          

            
Local Filesystem Access (Selected Workspaces Only)

            
AXEL only accesses directories you explicitly configure or drag into the application window. It reads files to extract metadata, generates SHA-256 hashes for deduplication, and monitors folder changes via the native OS kernel notification subsystem (inotify on Linux, kqueue on macOS, ReadDirectoryChanges on Windows). AXEL never scans your entire root filesystem.

          

          

            
Safe OS Trash Integration

            
When trashing duplicate files or removing obsolete items, AXEL dispatches them to your operating system's native trash bin using the platform's trash-cli/XDG/Finder API. Your files remain recoverable until you manually empty your system trash. Permanent unrecoverable deletion is only executed if explicitly confirmed.

          

          

            
Network Sockets & Port Binding

            
AXEL binds an embedded HTTP server to 127.0.0.1 (default port 8765) to provide the local REST API and Web UI. It never exposes ports to external interfaces unless you explicitly configure the host to 0.0.0.0. The only outbound network requests AXEL makes are HTTPS calls to Groq's API endpoint (api.groq.com) when an API key is configured and Force Offline Mode is disabled.

          

          

            
Zero Telemetry & Zero Data Collection

            
AXEL does not include Google Analytics, Sentry, Mixpanel, or any third-party telemetry libraries. No diagnostic beacons, crash telemetry, or usage metrics are transmitted over the network.

          

        


        
        

          

            
Automated PII & Credential Redaction Shield

            
Before any document text or code excerpt is dispatched to Groq's LLM endpoint, AXEL's privacy shield automatically detects and redacts high-risk sensitive patterns: passwords, API keys, private tokens, Aadhaar numbers, PAN numbers, Social Security numbers, credit card sequences, and personal email addresses. Sensitive tokens are replaced with [REDACTED_SECRET] or [REDACTED_ID] markers.

          

          

            
100% Air-Gapped / Force Offline Mode

            
For classified documents, proprietary intellectual property, or confidential legal files, you can toggle "Force Offline Mode" in Settings at any time. When active, AXEL shuts down all outbound network communication and categorizes files using local deterministic rule engines, TF-IDF symbol extractors, and vector space cosine similarity against pre-computed domain centroids.

          

          

            
Atomic Persistence & Crash Safety

            
Document indices and settings are written to temporary files (.tmp) and atomically committed via filesystem renames. If your system encounters a sudden power loss or crash, AXEL's index is never left in a corrupted state, and automatic backup snapshots (.bak) are maintained continuously.

          

        


        
        

          

            
Where to Get Your Groq API Key

            
1. Visit the Groq Console at https://console.groq.com/keys.

            2. Sign up or log in with your account.

            3. Click "Create API Key", give it a label (e.g. "Axel Desktop"), and copy the key string.

            4. Paste the key into AXEL Settings (AI & Cloud tab) and click "Test Key" to verify live latency.

          

          

            
Why Groq? (LPU Hardware Acceleration & Context Windows)

            
Groq runs on specialized Language Processing Unit (LPU) silicon rather than conventional GPUs. This architecture delivers 500+ tokens per second with typical round-trip request latencies under 180 milliseconds, turning document categorization from a sluggish background job into an instant, real-time interactive experience.


            Furthermore, Groq provides massive context windows (up to 128,000 tokens on models like Llama 3.3 70B), allowing AXEL to process comprehensive academic textbooks, long legal contracts, and dense multi-file source code repositories without aggressive chunking or context loss.

          

          

            
Dynamic Model Discovery & Open-Weights Freedom

            
AXEL queries the live Groq endpoint at runtime, automatically populating the available models for your account (such as Llama 3.3 70B, Llama 3.1 8B, Mixtral 8x7B, and Gemma 2 9B). You are never locked into a static list, and you can switch primary and fallback models dynamically as new architectures are released.
